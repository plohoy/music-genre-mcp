# Licence decisions

- MusicBrainz core data: CC0; store genre names and MBIDs.
- Wikidata structured data: CC0; store IDs, labels, aliases and supported claims.
- Wikipedia text: CC BY-SA; store only short attributed evidence fragments, never full articles.
- AcousticBrainz datasets: CC0 according to the project download page.
- FMA: preserve dataset attribution and use metadata/features only for validation.
